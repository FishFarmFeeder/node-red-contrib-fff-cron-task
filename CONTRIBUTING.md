# Contributing to node-red-contrib-fff-cron-task 🚀

First off, thanks for taking the time to contribute! 🎉

We love your input! We want to make contributing to this project as easy and transparent as possible, whether it's:

- Reporting a bug 🐛
- Discussing the current state of the code 💬
- Submitting a fix 🔧
- Proposing new features 💡

## How to Contribute

### Report Bugs
If you find a bug, please open an issue describing the problem, the expected behavior, and how to reproduce it.

### Suggest Enhancements
Have an idea to make this node even better? Open an issue with the tag `enhancement`. We'd love to hear your ideas!

### Pull Requests
1.  Fork the repo and create your branch from `main`.
2.  If you've added code that should be tested, add tests.
3.  Ensure the test suite passes.
4.  Make sure your code follows the existing style.
5.  Issue that pull request!

## Coding Style
- Keep it simple and readable.
- Use English for comments and variable names.

## Community
Be kind and respectful to others. Let's build something great together!
